# [!DNL Assets Essentials]의 비디오 편집 {#edit-videos}

에셋 사용자는 비디오에 대한 [!DNL Adobe Express] 빠른 작업이 임베드되어 있으므로 비디오 콘텐츠의 베리에이션을 쉽게 만들 수 있습니다. [!DNL Adobe Express]에서 제공하는 [!DNL Assets Essentials]의 빠른 작업은 비디오 자르기, 비디오 크기 조정, 비디오 트리밍, 비디오를 GIF으로 변환하는 등의 사용자 친화적인 비디오 편집 옵션을 제공합니다.

비디오를 편집하려면 비디오 세부 정보로 이동하여 [!UICONTROL 비디오 편집]을 클릭합니다. 또는 에셋을 선택하고 세부 정보를 클릭한 다음 오른쪽 창에 있는 ![가위](assets/do-not-localize/cut.svg) 아이콘을 클릭합니다. 비디오 편집 후 새 비디오를 새 버전 또는 새 에셋으로 저장할 수 있습니다.

[미리보기 인터페이스](/help/using/navigate-view.md#preview-assets)에 대해 자세히 알아보십시오.

## 사전 요구 사항 {#prerequisites}

[!DNL Adobe Express]에 액세스할 수 있는 권한이 필요하며 AEM Assets 내 하나 이상의 환경이 있어야 합니다. 환경은 [!DNL Assets as a Cloud Service] 또는 [!DNL Assets Essentials] 내의 저장소 중 하나일 수 있습니다.

## Adobe Express를 사용하여 비디오 편집 {#edit-video-using-express}

>[!CONTEXTUALHELP]
>id="assets_express_integration_videos"
>title="Adobe Express 통합으로 비디오 편집"
>abstract="이제 Experience Manager Assets에는 콘텐츠 재사용률과 콘텐츠 속도를 높이는 Adobe Express에서 제공하는 직관적인 비디오 편집 도구가 포함됩니다. 편집 옵션에는 비디오 트리밍, 자르기, 크기 조정 및 MP4를 GIF 파일로 변환 등이 포함됩니다."

임베드된 [!DNL Adobe Express] 빠른 작업을 사용하여 비디오를 완벽한 크기 및 방향으로 쉽게 변환할 수 있습니다.

### 비디오 자르기 {#crop-video-using-express}

임베드된 [!DNL Adobe Express] 빠른 작업을 사용하여 비디오에서 원하지 않는 부분을 제거할 수 있습니다. 이렇게 하려면 아래 단계를 수행합니다.

1. 비디오를 선택하고 **[!UICONTROL 편집]**&#x200B;을 클릭합니다.
2. 왼쪽 창에 있는 빠른 작업에서 **[!UICONTROL 비디오 자르기]**&#x200B;를 클릭합니다.
3. 비디오 모서리에 있는 핸들을 드래그하여 원하는 크기로 자르거나, 제공되는 화면 크기 중에서 원하는 크기를 선택합니다.
4. 비디오 음소거 또는 음소거 해제를 선택할 수 있습니다.
5. **[!UICONTROL 적용]**을 클릭합니다.
   ![Adobe Express로 비디오 자르기](/help/using/assets/adobe-express-crop-video.png)

   자른 비디오를 다운로드할 수 있습니다. 편집한 에셋을 동일한 에셋의 새 버전으로 저장하거나 새 에셋으로 저장할 수 있습니다. ![Adobe Express로 비디오 저장](/help/using/assets/adobe-express-save-video.png)

### 비디오 크기 조정 {#resize-video-using-express}

DAM의 최종 비디오 콘텐츠는 특정 채널에 배포하기 위해 크기를 조정해야 하는 경우가 많습니다. [!DNL Assets Essentials]에서 일반적인 소셜 채널에 필요한 크기에 맞게 비디오의 크기를 쉽게 조정할 수 있으며 사용자 정의 해상도에도 맞출 수 있습니다. [!DNL Assets Essentials]를 사용하여 비디오의 크기를 조정하려면 아래 단계를 수행합니다.

1. 비디오를 선택하고 **[!UICONTROL 편집]**&#x200B;을 클릭합니다.
2. 왼쪽 창에 있는 빠른 작업에서 **[!UICONTROL 비디오 크기 조정]**&#x200B;을 클릭합니다.
3. **[!UICONTROL 크기 조정]** 드롭다운 목록에서 소셜 미디어 플랫폼에 맞는 크기를 선택합니다. 또는 비디오 모퉁이의 핸들을 드래그하여 원하는 자르기를 만듭니다.
4. 필요한 경우 **[!UICONTROL 비디오 크기 조정]** 필드를 사용하여 비디오 크기를 조정합니다.
5. 비디오 음소거 또는 음소거 해제를 선택할 수 있습니다.
6. **[!UICONTROL 적용]**을 클릭하여 변경 내용을 적용합니다.
   ![Adobe Express로 비디오 크기 조정](/help/using/assets/adobe-express-resize-video.png)

크기를 조정한 비디오를 다운로드할 수 있습니다. 편집한 에셋을 동일한 에셋의 새 버전으로 저장하거나 새 에셋으로 저장할 수 있습니다.

### 비디오 트리밍 {#trim-video-using-express}

더 큰 비디오의 클립을 사용해야 하는 경우 &quot;비디오 트리밍&quot; 기능을 사용하여 비디오의 일부를 선택하고 트리밍할 수 있습니다. 아래의 단계를 수행하십시오.

1. 비디오를 선택하고 **[!UICONTROL 편집]**&#x200B;을 클릭합니다.
2. 왼쪽 창의 빠른 작업에서 **[!UICONTROL 비디오 트리밍]**&#x200B;을 클릭합니다.
3. 비디오의 시작 및 종료 시간을 지정하여 비디오의 특정 부분을 트리밍합니다. 또는 비디오 모퉁이의 핸들을 드래그하여 원하는 트리밍을 만듭니다.
4. **[!UICONTROL 크기]** 드롭다운 목록에서 적절한 치수를 선택합니다.
5. 비디오 음소거 또는 음소거 해제를 선택할 수 있습니다.
6. **[!UICONTROL 적용]**을 클릭하여 변경 내용을 적용합니다.
   ![Adobe Express로 비디오 크기 조정](/help/using/assets/adobe-express-trim-video.png)

트리밍한 비디오를 다운로드할 수 있습니다. 편집한 에셋을 동일한 에셋의 새 버전으로 저장하거나 새 에셋으로 저장할 수 있습니다.

### 비디오를 GIF로 변환 {#convert-mp4-to-gif-using-express}

Adobe Express를 사용하여 MP4 비디오를 GIF 형식으로 빠르게 변환할 수 있습니다. 다음 단계를 실행합니다.

1. 비디오를 선택하고 **[!UICONTROL 편집]**&#x200B;을 클릭합니다.
2. 왼쪽 창의 빠른 작업에서 **[!UICONTROL GIF로 변환]**&#x200B;을 클릭합니다.
3. 원하는 품질에 따라 적절한 파일 크기를 선택합니다. 또한 가로, 세로 또는 사각형의 방향을 선택합니다.
4. 비디오 모퉁이의 핸들을 드래그하여 원하는 자르기를 만듭니다.
5. **[!UICONTROL 적용]**&#x200B;을 클릭합니다.

   ![Adobe Express를 사용하여 비디오를 GIF로 변환](/help/using/assets/adobe-express-convert-video-to-gif.png)

비디오를 GIF 형식으로 다운로드할 수 있습니다. 편집한 에셋을 동일한 에셋의 새 버전으로 저장하거나 새 에셋으로 저장할 수 있습니다.

## 제한 사항 {#limitations-video-adobe-express}

* MP4 형식의 비디오만 편집할 수 있습니다.

* 지원되는 최대 소스 파일 크기는 1GB입니다.

* 지원되는 비디오는 46픽셀보다 크고 모든 면에서 3840픽셀보다 작습니다.

* 지원되는 웹 브라우저는 Google Chrome, Firefox, Safari 및 Edge입니다.

* 이 기능은 웹 브라우저의 시크릿 모드에서 열 수 없습니다.
